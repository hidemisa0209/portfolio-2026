WORKS 制作物

おみくじアプリ Illustrator / Visual Studio Code

  • 課題制作
  • # Web
  • # UIデザイン

  • 概要

    課題制作として制作したWebおみくじアプリです。
    おみくじを引くだけでなく、世界観も楽しめるコンテンツを目指して制作しました。

  • ターゲット

    おみくじや和風デザインが好きな方をはじめ、ゲーム感覚で気軽に楽しみたい方をターゲットに設定しました。
    思わず何度も引きたくなるような体験を意識しています。

  • コンセプト

    一般的な和風デザインではなく、他作品との差別化を図るため、大正レトロの世界観を取り入れました。
    デザインだけでなく、おみくじの結果や文章表現にも大正らしい言い回しを取り入れ、細部まで統一感のある世界観を演出しています。また、制作後には複数人にテストプレイを依頼し、実際に寄せられた意見をもとにUIや演出を改善しました。
    さらに、ソースコードを見ると「裏吉」が表示される隠し要素を用意するなど、遊び心のある仕掛けも取り入れています。

  • 制作期間

    約1週間

  • 担当範囲

    デザイン / コーディング
