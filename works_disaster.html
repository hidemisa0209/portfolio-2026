WORKS 制作物

家庭用防災LP Figma / CLIP STUDIO PAINT / Visual Studio Code

  • 課題制作
  • # Web
  • # グラフィックデザイン
  • # イラスト

  • 概要

    エム・シーシー食品株式会社様から実際に依頼を受け、1年次の進級制作として制作した家庭用防災をテーマにしたランディングページです。※PCサイズでの制作が課題条件だったため、SPサイトの作成は行っていません。

  • ターゲット

    家庭で防災に備えたい20〜30代の子育て世代をメインターゲットに設定しました。
    また、防災グッズや非常食に興味がある方や、親子で楽しく防災について学びたい方、日頃から防災意識を高めたい方を想定しています。

  • コンセプト

    「安心感と『考えるきっかけ』をつくる家庭用防災サイト」をコンセプトに制作しました。
    MCCのコーポレートカラーである赤を基調とし、親しみやすく明るい印象を与えるデザインを意識しています。家庭向けのサイトとして、防災の重要性をわかりやすく伝えながら、堅い印象になりすぎないようイラストやあしらいを取り入れ、楽しく読み進められる構成にしました。LPを通して、防災を「知る」だけでなく、家族で話し合うきっかけとなることを目指しています。

  • 制作期間

    約3ヶ月

  • 担当範囲

    デザイン / イラスト（アニメーション） / コーディング

  • URL

    https://hidemisa0209.github.io/disaster-pc/
